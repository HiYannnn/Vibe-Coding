# Swedish Election Guide

[Open the guide](https://minvalguide.vercel.app)

I built this small guide to make Sweden’s elections easier to understand,
with information available in Swedish, English, and Chinese.

The guide walks through voting eligibility, helps visitors explore national
and local parties, and presents the 2022 Riksdag election results. It focuses
on Sweden’s 2026 elections.

Built with HTML, CSS, and JavaScript. The website files are in `dist/`,
and the site is hosted on Vercel.
